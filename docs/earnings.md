# 분기 연결 영업실적 자료

삼성전자·SK하이닉스·NAVER가 2020~2024년에 발표한 2019년 4분기부터 2024년 3분기까지의 연결 영업이익을 조사했다. 기업·분기 조합 60개마다 이투데이 원문에서 영업이익 또는 영업손실을 처음 확인할 수 있었던 시각을 기록했다. 각 행에는 이투데이 기사와 당시 공시의 링크가 있다. [분기 실적 원장](../research/earnings.json)

| 기업 | 발표 | 최초 기사에서 전년 동기 영업이익 증감률 확인 | 손익 전환 | 증감률 미기재 |
|---|---:|---:|---:|---:|
| 삼성전자 | 20 | 18 | 0 | 2 |
| SK하이닉스 | 20 | 11 | 8 | 1 |
| NAVER | 20 | 20 | 0 | 0 |

## 공시에서 발표일 확인하기

1. DART의 기업별 검색에서 종목코드 005930, 000660, 035420을 각각 지정한다. 각 기업에 대해 2020년부터 2024년까지 한 해씩 검색한다. 공시유형은 거래소공시 중 공정공시(`I002`)를 선택하고, 최종보고서 필터를 해제해 최초 제출분도 포함한다. 해당 15개 검색에서 보고서명에 ‘잠정’과 ‘실적’이 들어가고 ‘안내’가 없는 제출분은 122개였다. 이 중 102개가 연결 실적이고 20개가 별도 실적이다. [DART 공시검색 안내](https://dart.fss.or.kr/guide/main.jsp?menu=121)
2. 연결 실적 공시의 표에서 당기 대상 기간을 확인하고, 해당 분기의 수치를 처음 공개한 제출분을 선택한다. 표의 영업이익 **당해실적**이 그 분기의 값이다. 4분기에는 연간 누계가 같은 표에 실리기도 한다. 삼성전자는 월초에 잠정 실적을 발표하고 월말에 상세 실적을 발표하므로 월초 발표를 선택했다. 원장에 기업·분기별 최초 제출번호와 발표일을 보존했다. [삼성전자 2019년 4분기 최초 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20200108800034) · [후속 상세 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20200130800057)
3. 삼성전자 20건과 NAVER 18건은 해당 DART 공개표, SK하이닉스 20건과 NAVER 2건은 당일 회사 보도자료에서 분기 영업이익·손실을 대조했다. 원장의 `official_url`이 실제 사용한 대조 자료다. 금액 단위는 억 원이다. 비교 기준이 재작성되는 경우가 있어 전년 기사의 이익을 가져와 증감률을 다시 계산하지 않는다. [SK하이닉스 2020년 실적 및 4분기 비교](https://news.skhynix.co.kr/2020-business-performance/) · [NAVER 2024년 2분기](https://navercorp.com/media/pressReleasesDetail?seq=31958) · [NAVER 2024년 3분기](https://navercorp.com/media/pressReleasesDetail?seq=32132)

## 이투데이 기사 선택하기

60개 기업·분기 중 두 기업이 같은 날 발표해 달력상 발표일은 59일이었다. 발표일마다 이투데이의 해당 일자 사이트맵에서 기업명이 제목에 나타나는 기사 전체를 후보로 삼았다. 기존 뉴스 수집기의 기업명·영문명 표기를 그대로 사용했다. 전체 개발기간 월별 XML에만 있는 기사들도 기존 수집기가 메타데이터를 확인했으며, 그중 기업명 제목 조건에 맞는 기사는 없었다. 기업명이 제목에 없는 기사나 다른 매체의 선행 보도까지 포함하는 전수 시각으로 해석할 수는 없다. [이투데이 일자별 목록 예시](https://www.etoday.co.kr/sitemap/?year=2020&month=1&day=8) · [제목 선별 및 월별 목록 대조 코드](../src/news_archive.py)

후보 667건의 본문·발행시각·수정시각을 읽었다. 최초판을 따로 확보하지 못한 수정기사는 수정시각을 사용했다. 기업·분기별로 사용 가능 시각이 빠른 순서대로 검토하며 같은 분이면 숫자 기사 ID가 작은 쪽을 먼저 읽었다. 기사에 해당 분기의 실제 연결 영업이익·손실 금액이 있고, 당시 공시 금액과 단위·반올림을 고려해 일치하는지 확인했다. 60개 선정 기사 중 7개에 수정시각이 있었고, 선정 기사의 발행·수정으로 신호 거래일이 달라진 사례는 없었다. 최초 사용 가능 시각은 07시 44분부터 09시 34분까지였다. [삼성전자 최초 기사 예시](https://www.etoday.co.kr/news/view/1842595) · [SK하이닉스 손익 전환 기사 예시](https://www.etoday.co.kr/news/view/2412437)

선정 기사보다 먼저 나온 43건은 연간 합계만 실은 기사 13건, 전망·예고 12건, 다른 주제 8건, 액수 없는 공시 일정 5건, 분기 매출만 실은 기사 4건, 연간과 분기 구분이 불명확한 기사 1건이다. 각 건의 기사 ID·사용 가능 시각·본문 해시·제외 사유를 `earlier_reviews`에 보존했다. 매출만 앞서 보도한 4개 속보는 `earlier_quarterly_sales_article`에서도 확인할 수 있다. 이후 564건과 후속 확정 실적은 별도 분기 사건으로 세지 않았다.

## 일별 입력과 재현

기업별 최초 기사에 명시된 **전년 동기** 증감률을 기사 정밀도대로 입력했다. 예를 들어 삼성전자 2020년 2분기 최초 기사에는 영업이익 8조 1000억 원만 있어 증감률을 결측으로 기록했다. 해당 분기의 후속 기사나 공식 자료에서 증감률을 가져와 소급 입력하지 않는다. 손실에서 이익으로, 또는 이익에서 손실로 바뀐 8건도 증감률을 결측 처리했다. 실적 원장에는 기사 금액과 공식 금액을 각각 보존했다. SK하이닉스 2022년 4분기의 첫 속보는 1조 7011억 원 손실, 회사 발표는 1조 7012억 원 손실로 표기가 달라 두 값을 기록했다. [증감률 미기재 기사](https://www.etoday.co.kr/news/view/1914712) · [손실 보도](https://www.etoday.co.kr/news/view/2217445) · [회사 발표](https://news.skhynix.co.kr/2022-business-performance/)

거래일 표에는 발표일에만 `earnings_release=1`을 기록한다. 해당 기사에 해석 가능한 증감률이 있으면 `earnings_yoy_available=1`이며, `earnings_op_yoy_pct`는 퍼센트 단위다. 예컨대 34.26% 감소는 `-34.26`이다. 미기재·손익 전환은 발표 표시 1, 가용 표시 0, 수치 0으로 인코딩한다. 비발표일은 세 필드가 모두 0이다. 사용 가능 시각을 기존 장 마감 달력에 맞추면 1,231거래일 × 3사 표에 발표 신호가 60회 생긴다. [시간 정렬 및 원장 검증 코드](../src/earnings.py)

저장소 최상위에서 아래 명령을 순서대로 실행한다. 첫 두 단계는 이투데이 목록·본문 로컬 캐시가 이미 완성됐으면 생략할 수 있다. 마지막 명령은 60개 발표일의 기업명 제목 후보를 다시 구성하고, 최초 기사와 앞선 제외 기사의 시각·본문 해시·검토 목록이 원장과 맞는지 확인한다.

```powershell
python -m src.news_archive
python -m src.contract_review collect
python -m src.earnings
```

검증 출력은 `60 releases, 667 release-day articles, 43 earlier exclusions verified`이다. 일별 입력은 계약 뉴스와 함께 `python -m src.news_events`에서 생성한다.
