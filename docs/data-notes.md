# 자료와 검증 방법

분석 단위는 삼성전자·SK하이닉스·NAVER 각각의 거래일이다. 2019년 11~12월은 이동통계 계산용이고, 입력표는 2020년 첫 거래일부터 2024년 마지막 거래일까지다. 산출물은 [학습 전 점검 결과](pretraining.md)에 정리했다.

## 주문 체결에 쓰는 가격

종목 시세는 FinanceData가 보관한 연도별 거래소 시세 스냅샷에서 보통주 종목코드로 추출했다. 2025년 1월에 저장된 고정 리비전에서 **2019~2024년 파일만** 읽는다. 과거 실제 거래가격이 필요한 계좌에는 이 자료의 비수정 시가·종가를 사용한다. KOSPI 거래일과 지수 종가는 날짜 범위를 지정할 수 있는 네이버 금융 일봉에서 가져왔다. [고정한 시세 아카이브](https://github.com/FinanceData/marcap/tree/eeb328584b54211da285a74c68d6e1d5dc7d6a91/data) · [네이버 금융의 기간 지정 일봉 예시](https://api.finance.naver.com/siseJson.naver?symbol=KOSPI&requestType=1&startTime=20200102&endTime=20200103&timeframe=day)

- 각 시계열은 준비 기간 포함 1,272거래일이다. 세 종목의 날짜가 지수 거래일과 모두 일치했고, 세 종목에서 거래량 0인 행은 없었다. 당시 결산표와도 2019년 마지막 거래일 세 종목의 종가를 대조했다. [당시 시황표](https://securities.miraeasset.com/bbs/download/2071036.pdf?attachmentId=2071036)
- 거래소 시세 아카이브와 네이버 일봉의 종목별 OHLCV를 대조했다. 삼성전자와 SK하이닉스는 전 항목이 일치했다. NAVER는 시가 5개, 고가 12개, 저가 16개 필드값에 차이가 있었고 종가·거래량은 모두 일치했다. 공급처별 차이를 평균 내지 않고 세 종목에 동일한 아카이브를 사용했다.
- Yahoo 일봉과도 별도로 대조했다. Yahoo에는 2022년 1월 3일과 5월 9일이 빠져 있었다. KOSPI 종가 차이가 있던 두 날은 당시 증권사 시황표의 2021년 4월 23일 3,186.10과 5월 6일 3,178.74로 확인했다. 네이버 지수 종가와 일치했다. [4월 23일 시황표](https://securities.miraeasset.com/public/mw/blog/20210426080238/20210426_Daily.pdf) · [5월 6일 시황표](https://ssl.pstatic.net/imgstock/upload/research/market/1620344511837.pdf)
- 수집 경로를 시험할 때 네이버의 다른 차트 API가 과거 날짜 요청에 범위 밖 최신 행을 반환했다. 이 경로를 제외했다. 저장·결합하는 수집기에서는 요청 범위를 벗어난 일봉이 하나라도 있으면 중단한다.

## 입력과 목표 열

| 열 | 계산 | 시간 기준 |
|---|---|---|
| `ret_5` | 오늘 종가 / 5거래일 전 종가 − 1 | 매 거래일 장 마감 |
| `ma_gap_20` | 오늘 종가 / 오늘 포함 20일 종가 평균 − 1 | 장 마감 |
| `volatility_20` | 최근 20개 일간 종가 수익률의 표본표준편차 | 오늘까지 21개 종가 |
| `market_ret_20` | KOSPI 20거래일 종가 수익률 | 장 마감 |
| `relative_strength_20` | 종목 20거래일 수익률 − KOSPI 20거래일 수익률 | 장 마감 |
| `relative_volume_20` | 오늘 거래량 / 직전 20거래일 거래량 평균 | 분모에서 당일 제외 |
| `contract_signed`, `contract_terminated`, `contract_reports` | 신규 체결·해지 사건 수, 중복 제거한 보도 수 | 해당 마감까지 공개·확인된 기사 |
| `target_up_5` | 다음 시가로부터 5번째 시가 간격을 지난 가격이 더 높으면 1, 같거나 낮으면 0 | 판단일이 t면 t+1 시가와 t+6 시가로 확정 |

입력표에는 검산용 날짜·목표 열도 있다. 학습 코드는 위 시세 변수와 선택한 뉴스 변수만 명시적으로 읽는다. 1·10일 목표는 지도학습 민감도 비교용이고, 실제 보유 여부는 매일 다시 판단한다. 가격에는 배당금을 더하지 않고, 계좌에서 별도 처리한다. 주식 수가 바뀌는 분할을 가로지르면 거래 단위를 맞춘다. 보조 자료에서 개발 기간에 세 종목의 분할 기록은 없었다.

## 서버로 넘기는 범위

서버에서는 종목별 2022·2023·2024년 검증부터 실행한다. 뉴스 유무 비교는 같은 종목·날짜·시드에 맞추고, 뉴스 미사용 대조군에는 해당 열의 값을 0으로 고정한다. 두 조건의 입력 차원이 같아 뉴스가 전부 0인 경우 트리의 변수 추출 방식도 같다. FQI 탐색 경로는 같은 시드에서 두 조건이 공유한다. 2025년 최종 평가는 개발 결과에 따라 모델과 설정을 확정한 후의 별도 단계다.
